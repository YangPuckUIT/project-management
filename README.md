## Course Contents

| Lecture | Topics |
|---|---|
| **Lec 1: Introduction to Project Management** | Overview of project management<br>Project concepts and fundamentals |
| **Lec 2: Process, Lean and Agile** | Project management processes<br>Lean principles<br>Agile methodologies |
| **Lec 3: Lean-Agile Workshop** | Applying Lean and Agile practices<br>Workshop activities and discussions |
| **Lec 4: Scope Management** | Defining project scope<br>Requirements management<br>Work Breakdown Structure (WBS) |
| **Lec 5: Schedule Management** | Activity planning<br>Project scheduling<br>Critical Path Method (CPM) |
| **Lec 6: Cost Management** | Cost estimation<br>Budget planning<br>Cost control |
| **Lec 7: Risk Management** | Risk identification<br>Risk analysis and response strategies |
| **Lec 8: Quality Management** | Quality planning<br>Quality assurance and quality control |
| **Lec 9: All Knowledge Areas** | Overview of project management knowledge areas |
